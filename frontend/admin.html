Authentification Ingénieur

Cet espace permet de gérer les gammes, options, règles de compatibilité et grilles d'articles Agile.

Créer une nouvelle gamme

Crée une gamme vide (code, libellé, description). Les groupes d'options, les options et la grille se saisissent ensuite dans les écrans ci-dessous une fois la gamme sélectionnée — comme pour une gamme existante. Agile ne connaît que les articles, pas la configuration qui les relie : cette partie reste toujours une saisie manuelle.
